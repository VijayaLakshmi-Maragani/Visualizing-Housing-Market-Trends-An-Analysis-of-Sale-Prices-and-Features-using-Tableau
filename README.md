# 🏡 Visualizing Housing Market Trends  
### 📊 An Analysis of Sale Prices and Features using Tableau  

---

## 📖 Project Overview  

This project analyzes housing market trends for **ABC Company** using **Tableau**.  
The goal is to understand the key factors influencing house prices and sales patterns by examining features such as:

- 🏠 Years since renovation  
- 🛁 Number of bathrooms  
- 🛏️ Number of bedrooms  
- 🏢 Number of floors  
- 🧱 Basement area  
- 📅 House age  

By transforming and visualizing housing data, this project helps stakeholders make data-driven decisions, optimize pricing strategies, and improve market competitiveness.

---

## 🎯 Business Objective  

ABC Company faced challenges in identifying:

✔️ What drives house prices  
✔️ How renovations impact sales value  
✔️ How house age affects demand  
✔️ Feature trends across the housing inventory  

This project provides interactive visual dashboards to uncover hidden insights in housing data.

# 📊 Project Scenarios & Visualizations  

---

## 🔹 Scenario 1: Overall Data Overview  

### 📌 Visualization Type: KPI Summary Dashboard  

This view provides:

- 📊 Total number of housing records  
- 💰 Average Sale Price  
- 🧱 Total Basement Area (sqft)  

### 🎯 Purpose:
Gives stakeholders a quick understanding of dataset scale and key performance indicators.

### 📈 Insight Example:
- Average sale price shows overall market value.
- Basement area contributes significantly to property valuation.

---

## 🔹 Scenario 2: Total Sales by Years Since Renovation  

### 📌 Visualization Type: Histogram  

This chart shows:

- Distribution of sales prices  
- Categorized by years since renovation  

### 🎯 Purpose:
To understand how recently renovated houses influence price ranges.

### 📈 Insight Example:
- Recently renovated houses tend to fall into higher price bins.
- Older renovations show lower pricing trends.

---

## 🔹 Scenario 3: Distribution of House Age by Renovation Status  

### 📌 Visualization Type: Pie Chart  

This visualization shows:

- Age group distribution  
- Renovated vs Not Renovated houses  

### 🎯 Purpose:
To analyze how house age correlates with renovation patterns.

### 📈 Insight Example:
- Majority of houses fall within mid-age category.
- Renovations are more common in older houses.

---

## 🔹 Scenario 4: House Age Distribution by Bathrooms, Bedrooms & Floors  

### 📌 Visualization Type: Grouped Bar Chart  

This chart categorizes:

- House age  
- Number of bedrooms  
- Number of bathrooms  
- Number of floors  

### 🎯 Purpose:
To examine how structural features vary across different house age groups.

### 📈 Insight Example:
- Newer houses typically have more bathrooms and modern layouts.
- Older houses often have fewer floors.
